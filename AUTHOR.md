## Tentang Repository

`project-pertama` merupakan repository pembelajaran yang berisi panduan dasar penggunaan Git dan GitHub bagi mahasiswa, pelajar, dan programmer pemula.

Materi disusun menggunakan Bahasa Indonesia dengan istilah teknis dalam Bahasa Inggris untuk membantu pembaca memahami konsep version control dan mempraktikkan perintah Git secara langsung.

## Tujuan

Repository ini bertujuan untuk:

1. Memperkenalkan Git dan GitHub kepada pemula.
2. Menjelaskan perintah Git beserta fungsi dan penggunaannya.
3. Memberikan panduan praktik membuat repository dari awal.
4. Membantu pembaca memahami proses `git init`, `git add`, `git commit`, dan `git push`.
5. Menjadi bahan belajar yang dapat digunakan dan dikembangkan lebih lanjut.
